# BABYDEN RING

おむつの赤ちゃんが武器を振り回す、激ムズ2Dボスラッシュ・ブラウザゲーム。

公開URL: https://ryu2013.github.io/BABYDEN-RING/

- セーブ機能なし。ボスを倒すとパスワードが表示され、次回そのパスワードを入力すると該当ステージから再開できる。
- 撃破タイムを表示（ベストタイムの保存は未実装）。
- 素のHTML/CSS/JS + Canvas 2D API、ビルドステップなし。
- キャラクター・ボス・背景はローカルのComfyUI(Stable Diffusion)で生成。

## ローカルで動かす

ESモジュールを使っているため `file://` では動かない（CORSでブロックされる）。簡易サーバー経由で開く。

```bash
cd ~/projects/babyden-ring
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く。`?debug=1` を付けると当たり判定の可視化と `window.__game` からの状態参照が有効になる。

## 主人公を選ぶ

タイトル画面で3人から選ぶ。定義は `js/characters.js` に集約されていて、FSMは共通・数値だけが違う。

| | つるぎベイビー | ハンマーベイビー | ゆみベイビー |
| --- | --- | --- | --- |
| タイプ | バランス | 重量 | 遠距離 |
| HP | 100 | 132 | 78 |
| 被ダメージ倍率 | 1.0 | 0.7 | 1.3 |
| スタミナ | 100 | 92 | 145 |
| 弱 / 強攻撃 | 8 / 34 | 15 / 54 | 9 / 24（矢） |
| 強攻撃の発生 | 16F | 25F | 18F |
| 体幹 | 10 | 14 | 8 |

ゆみベイビーの攻撃は近接判定を持たず矢を飛ばす。外した矢は空振り扱いになり自分の体幹が削れる。

## 操作方法

### キーボード（PC）
| 操作 | キー |
| --- | --- |
| 移動 | ← → / A D |
| ロール（回避・無敵あり） | **Space** / Z / S / Shift |
| 弱攻撃 | J / X |
| 強攻撃（長押しで溜め） | K / C |
| ガード / パリィ（長押し） | L / V |
| ジャンプ | ↑ / W |

ロールはSpaceを主キーにしている。Shiftは環境によってIMEやアクセシビリティ機能に横取りされ、実機で反応しない事例があったため補助扱い。

硬直中に押した入力は約0.5秒ぶん記憶され、動けるようになった瞬間に発動する。攻撃・ロールの硬直の終盤は次の行動でキャンセルできる。

### スマホ
画面下部の固定ボタン（左下: 移動・ジャンプ / 右下: ロール・弱攻撃・強攻撃・ガード）。強攻撃ボタンは押しっぱなしで溜められる。

## 戦い方

### 予備動作を見る
ボスは攻撃前に光り、足元に危険範囲とゲージが出る。ゲージが満ちた瞬間に判定が出る。

- **赤い予告** … ガード・パリィ・ロールのどれでも対処できる
- **黄色い破線の予告** … ガード不可。ロールで逃げるしかない

低い判定の足払いはジャンプで跨ぐ、突進は敵側にロールして抜ける、ディレイ攻撃はロールを我慢する、と攻撃ごとに正解が違う。

### パリィ
相手の攻撃が当たる瞬間に**ガードを押し直す**と成功する（ガード開始から7フレーム以内）。ノーダメージで受け止め、スタミナが少し回復し、相手の体幹を5削る。押しっぱなしでは成立しない。ガード不可攻撃はパリィできない。

### 体幹ゲージ
HPバーの下の細いバー。0になると数秒間動けなくなる。時間で自動回復する。

| | 敵の体幹が減る | 自分の体幹が減る |
| --- | --- | --- |
| 弱攻撃を当てる/外す | -1 | 外して -1 |
| 強攻撃を当てる/外す | -3（溜めで最大-5） | 外して -2 |
| パリィ成功 | -5 | — |
| 攻撃を受ける | — | -1 |

敵の体幹を崩している間は与ダメージが2.4倍になる。逆に振り回すだけだと自分が先に崩れて袋叩きにされる。

### 強攻撃の溜め
強攻撃ボタンを押しっぱなしにすると3段階までチャージされる。段階が上がるとオーラの色と輪の数が変わる。

| 段階 | 溜め | 威力 | リーチ | 追加スタミナ |
| --- | --- | --- | --- | --- |
| 1 | 0F | ×1.0 | — | — |
| 2 | 26F | ×1.7 | +14 | +12 |
| 3 | 58F | ×2.5 | +30 | +22 |

96フレームで自動的に放たれる。溜め中はロールでキャンセルできる。

### スタミナ
ロール・攻撃・ガードで消費し、足りないと行動できない。ガード中に消費しきるとガードが崩れて直撃を受ける。

## ボス

### ステージ1: よちよちドール
第1形態で7種、第二形態で10種の攻撃パターンを持つ。横なぎ / ディレイ振り下ろし / 2連撃 / 3連撃 / ガラガラ投げ（遠距離）/ 足払い / 突進 / おしり落とし（ガード不可）/ 泣き叫び（広範囲・ガード不可）/ 高速4連撃、加えてバックステップで距離を取る。プレイヤーが強攻撃を溜めているのを見ると高確率で回避する。

**HPを0にしても倒れない。** ひび割れドールへ進化し、HP200・攻撃力1.3倍・予備動作0.7倍でもう一戦になる。

### ステージ2: やけどのクマさん
横なぎと突進。（第二形態は未実装）

## コードの構成

```
js/
├── main.js          ゲームループ、当たり判定の解決、イベントの配線
├── characters.js    主人公3種の数値定義
├── stages.js        ボスと攻撃パターンの定義（データ）
├── effects.js       パーティクル・斬撃・文字などの視覚効果
├── projectiles.js   矢と飛び道具
├── renderer.js      Canvas描画
├── ui.js            DOMオーバーレイ（HUD・キャラ選択・各画面）
├── input.js         キーボード/タッチ → アクションの変換と入力バッファ
└── entities/
    ├── player.js    プレイヤーFSM、パリィ、体幹、チャージ
    └── boss.js      ボスFSM（steps方式）、体幹、形態変化
```

ボスの攻撃は `steps` の配列で表す。`windup`(予備動作) / `active`(判定) / `gap`(次の一撃までの間) を並べるだけで、連撃もディレイ攻撃も同じ仕組みで書ける。

```js
combo3: {
  recoveryFrames: 44,
  steps: [
    { windup: 30, active: 7, gap: 10, damage: 12, hitbox: {...} },
    { windup: 10, active: 7, gap: 8,  damage: 12, hitbox: {...} },
    { windup: 26, active: 10,         damage: 24, hitbox: {...} },  // 最後だけディレイ
  ],
},
```

`projectile` を持たせれば遠距離攻撃、`unblockable: true` でガード不可、`move: 'away'` で回避行動になる。

## 素材の生成

ローカルのComfyUIを使う。先にサーバーを起動しておく。

```bash
cd ~/projects/twitter-manga-bot/comfyui/ComfyUI
./.venv/bin/python main.py --listen 127.0.0.1 --port 8188
```

別のターミナルで:

```bash
cd ~/projects/babyden-ring
python3 tools/gen_assets.py                 # 全部生成 (assets/raw/ に出る)
python3 tools/gen_assets.py bow_idle        # 一部だけ作り直す

# 背景を抜いてゲーム用サイズに縮小 (assets/ に出る)
~/projects/twitter-manga-bot/comfyui/ComfyUI/.venv/bin/python tools/cutout.py
```

プロンプトとシードは `tools/gen_assets.py` の `ASSETS` にまとまっている。主人公は素体プロンプト(`BABY_CORE`)とシードを使い回すことでポーズ違いでも同じキャラに見えるようにしている。キャラの同一性をさらに上げる方法は `characters/README.md` を参照。
