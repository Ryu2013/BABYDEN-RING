# BABYDEN RING

おむつの赤ちゃんが武器を振り回す、激ムズ2Dボスラッシュ・ブラウザゲーム。

公開URL: https://ryu2013.github.io/BABYDEN-RING/

- セーブ機能なし。ボスを倒すとパスワードが表示され、次回そのパスワードを入力すると該当ステージから再開できる。
- 撃破タイムを表示（ベストタイムの保存は未実装）。
- 素のHTML/CSS/JS + Canvas 2D API、ビルドステップなし。
- キャラクター・ボス・背景はローカルのComfyUI(Stable Diffusion)で生成。

## ローカルで動かす

ESモジュールを使っているため `file://` では動かない（CORSでブロックされる）。簡易サーバー経由で開く。

```bash
cd ~/projects/babyden-ring
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く。`?debug=1` を付けると当たり判定の可視化と `window.__game` からの状態参照が有効になる。

## 主人公を選ぶ

「たたかう」を選ぶと生まれ（主人公）の選択画面になる。定義は `js/characters.js` に集約されていて、FSMは共通・数値だけが違う。

| | つるぎベイビー | ハンマーベイビー | ゆみベイビー |
| --- | --- | --- | --- |
| タイプ | バランス | 重量 | 遠距離 |
| HP | 100 | 132 | 72 |
| 被ダメージ倍率 | 1.0 | 0.7 | 1.45 |
| スタミナ | 100 | 92 | 104 |
| 弱 / 強攻撃 | 8 / 34 | 14 / 40 | 5 / 14（矢） |
| 溜められる段階 | 2段階 | 3段階 | 溜められない |
| 弱攻撃の届く距離 | 112px | 110px | 300px（矢） |
| 強攻撃の発生 | 16F | 25F | 18F |
| 体幹 | 10 | 14 | 8 |
| エスト瓶 | 3 | 3 | 3 |

ゆみベイビーの攻撃は近接判定を持たず矢を飛ばす。矢の届く距離は弱で約300px・強で約340pxしかなく、闘技場の幅1920pxに対してかなり短い。撃つたびにスタミナを大きく削るので撃ち続けられず、外した矢は空振り扱いで自分の体幹も削れる。

## 操作方法

ボタンは少ない。ロール・ガード・弱強の切り替えはすべて「押し方」で表す。

### キーボード（PC）
| 操作 | キー |
| --- | --- |
| 移動 | ← → / A D |
| ロール（回避・無敵あり） | 同じ方向を**素早く2回** / Space・Z・Shift |
| 弱攻撃 | 攻撃キーを**押してすぐ離す**（J / K / X）。ジャンプ中も出せる |
| 強攻撃 | 攻撃キーを**押し続ける**（離すと放つ） |
| パリィ | 敵の一撃に**合わせて攻撃キーを押す** |
| ジャンプ | ↑ / W |
| エスト瓶 | F / R |

### スマホ
**横画面専用。** 縦向きのときは「端末を横向きに」の案内だけを出し、ゲームは始まらない。
ボタンは5つだけ（◀ ▶ 瓶 跳 攻）で、画面の左右の隅に置いてある。HUDは上端に寄せてあるのでボタンと重ならない。

- ロール … ◀ か ▶ を素早く2回タップ
- 弱攻撃 … 攻をタップ（ジャンプ中も出せる）
- 強攻撃 … 攻を長押し（離すと放つ）
- パリィ … 敵の攻撃に合わせて攻を押す

硬直中に押した入力は約0.5秒ぶん記憶され、動けるようになった瞬間に発動する。攻撃・ロールの硬直の終盤は次の行動でキャンセルできる。

## 闘技場

横1920px（画面の2倍）。カメラがプレイヤーとボスの中間を追いかけ、背景は半分の速さで流れる。端まで逃げても、ボスは走って詰めてくる（間合いが開いているあいだは立ち止まって攻撃せず、走ることを優先する）。

**体はすり抜けられる。** ロールをしなくてもボスの向こう側へ回り込める。重なっているだけでは何も起きないが、ボスの近接攻撃の判定は自分の足元まで届くので、真下は安地にならない。

## 戦い方

### 向き
**常に敵の方を向く**（ロックオン）。左右の入力は移動だけに使うので、後退しながら敵を見続けられる。スマホでも向きを合わせる操作は要らない。

ただし**予備動作に入ったら振り向けない**。これは自分もボスも同じで、遠距離攻撃の構えを見てから背後に回れば、その一撃は空を切る。

### 予備動作を見る
危険範囲やゲージの表示は無い。**構えの絵だけが手がかり**になる。腕を振りかぶれば振り下ろし、腕を後ろに引けば投擲、低く沈めば足払い、前傾すれば突進、のけぞれば絶叫。攻撃の直前はボスが赤く染まり、ガード不可の技だけは黄色く染まる。

低い判定の足払いはジャンプで跨ぐ、突進は敵側にロールして抜ける、ディレイ攻撃はロールを我慢する、と攻撃ごとに正解が違う。

### パリィ
**ガードは無い。** 相手の攻撃が当たる瞬間に攻撃ボタンを押すと、それがパリィになる（押してから8フレーム以内に被弾すれば成立）。ノーダメージで受け止め、スタミナが少し回復し、相手の体幹を5削る。外せばただの攻撃が出るだけなので、被弾する。ガード不可（黄色い予告）はパリィできない。

### エスト瓶
HPを最大値の55%回復する。3回まで。飲み始めてから効くまで約0.5秒あり、その間は完全に無防備。ボスは回復の気配を見ると距離を詰めてくる。

### 体幹
**ゲージは表示しない**（内部の数値として持っているだけ）。0になると数秒間動けなくなり、頭上に星が回って「体幹崩し！」と出る。時間で自動回復する。

| | 敵の体幹が減る | 自分の体幹が減る |
| --- | --- | --- |
| 弱攻撃を当てる/外す | -1 | 外して -1 |
| 強攻撃を当てる/外す | -3（溜めで最大-5） | 外して -2 |
| パリィ成功 | -5 | — |
| 攻撃を受ける | — | -1 |

敵の体幹を崩している間は与ダメージが2.4倍になる。逆に振り回すだけだと自分が先に崩れて袋叩きにされる。

### 強攻撃の溜め
攻撃ボタンを押しっぱなしにすると3段階までチャージされる。段階が上がるとオーラの色だけでなく**絵そのものが変わる**。

| 段階 | 溜め | 威力 | リーチ | 追加スタミナ |
| --- | --- | --- | --- | --- |
| 1 | 0F | ×1.0 | — | — |
| 2 | 28F | ×1.35 | +12 | +12 |
| 3 | 64F | ×1.7 | +26 | +22 |

**溜められる段階はキャラごとに違う。** ハンマーは3段階まで、つるぎは2段階まで、ゆみは溜められない（押し続けても威力は上がらず、上限に達したら自動で放たれる）。

104フレームで自動的に放たれる。**溜めている間は一歩も動けない。** 溜め中はロールでキャンセルできるが、ボスは溜めを見ると高確率で距離を取る。スタミナは放つ瞬間に払うので、足りない状態からでも溜め始められる（溜めている間に回復する）。

### スタミナ
ロール・攻撃・エスト瓶で消費し、足りないと行動できない。

## ボス

### よちよちドール
第1形態で11種、第二形態で14種の攻撃パターンを持つ。

**通常技** … 横なぎ / ディレイ振り下ろし / 2連撃 / 3連撃 / 高速4連撃 / ガラガラ投げ（遠距離）/ 足払い（ジャンプで跨ぐ）/ 突進 / おしり落とし（ガード不可）/ 泣き叫び（広範囲・ガード不可）

**大技**（頻度は低い。第二形態では1.8倍出やすくなる）

| 技 | 対処 |
| --- | --- |
| 突き | 336px を一息で踏み込む。速く長いのでロールでは抜けにくい。早めに退くかジャンプ |
| 地面全体の足踏み | 闘技場の端から端まで届く低い判定。**ジャンプでしか避けられない**。発動前に床全体が赤く光る |
| 矢の雨 | 9本の矢が時間差で空から降る。落ちてくる位置を見て動く |
| 溜め叩きつけ | 力を溜める構えのあと広範囲・ガード不可の一撃。溜めを見たら離れるか殴りに行く |

**予備動作の長さは技によって違う。** 横なぎや足払いは26フレームで飛んでくるが、大技は72〜102フレームかけて構える。第二形態では全体が速くなるものの、大技だけは読む時間が残るようにしてある。

**連撃は一撃ごとに構えが変わる**ので、何発来るかを構えで読める（例: 3連撃は 振りかぶり → 突き → 振り下ろし）。**大技は構えが2回変わる**（例: 床攻撃は 力を溜める → 足を振り上げる）ので、1つ目の構えを見た時点で「大技が来る」と分かる。

**回避もする。** 転がって距離を取り、その間は攻撃が当たらない。プレイヤーが強攻撃を溜めているのを見ると高確率で回避する。

**スタミナを持つ**（ゲージは見せない）。攻撃のたびに消費し、尽きると息切れして約1.5秒動けなくなる。この間は被ダメージが2倍。

攻撃の種類ごとに**構えの絵が違う**。腕を振りかぶれば振り下ろし、腕を後ろに引けば投擲、低く沈めば足払い、前傾すれば突進。この構えを見て何が来るかを読む。

離されると飛び道具を投げてから一気に距離を詰め、体幹を削られると自分から距離を取る。

**HPを0にしても倒れない。** ひび割れドールへ進化する。姿は炭化して割れ目から赤い光が漏れ、一回り大きくなる。HP280・攻撃力1.3倍・予備動作0.7倍でもう一戦。

## コードの構成

```
js/
├── main.js          ゲームループ、当たり判定の解決、イベントの配線
├── characters.js    主人公3種の数値定義
├── stages.js        ボスと攻撃パターンの定義（データ）
├── effects.js       パーティクル・斬撃・文字などの視覚効果
├── projectiles.js   矢と飛び道具
├── renderer.js      Canvas描画
├── ui.js            DOMオーバーレイ（HUD・キャラ選択・各画面）
├── input.js         キーボード/タッチ → アクションの変換と入力バッファ
└── entities/
    ├── player.js    プレイヤーFSM、パリィ、体幹、チャージ
    └── boss.js      ボスFSM（steps方式）、体幹、形態変化
```

ボスの攻撃は `steps` の配列で表す。`windup`(予備動作) / `active`(判定) / `gap`(次の一撃までの間) を並べるだけで、連撃もディレイ攻撃も同じ仕組みで書ける。

```js
combo3: {
  recoveryFrames: 44,
  steps: [
    { windup: 30, active: 7, gap: 10, damage: 12, hitbox: {...} },
    { windup: 10, active: 7, gap: 8,  damage: 12, hitbox: {...} },
    { windup: 26, active: 10,         damage: 24, hitbox: {...} },  // 最後だけディレイ
  ],
},
```

`projectile` を持たせれば遠距離攻撃、`unblockable: true` でガード不可、`move: 'away'` で回避行動になる。

## 素材の生成

ローカルのComfyUIを使う。先にサーバーを起動しておく。

```bash
cd ~/projects/twitter-manga-bot/comfyui/ComfyUI
./.venv/bin/python main.py --listen 127.0.0.1 --port 8188
```

別のターミナルで:

```bash
cd ~/projects/babyden-ring
python3 tools/gen_assets.py                 # 全部生成 (assets/raw/ に出る)
python3 tools/gen_assets.py bow_idle        # 一部だけ作り直す

# 背景を抜いてゲーム用サイズに縮小 (assets/ に出る)
~/projects/twitter-manga-bot/comfyui/ComfyUI/.venv/bin/python tools/cutout.py
```

タイトルロゴは生成画像ではなく `tools/make_logo.py` が書体（Cinzel）と図形から組み立てる。環状の紋章の中心におしゃぶりのシルエットを忍ばせてある。

```bash
~/projects/twitter-manga-bot/comfyui/ComfyUI/.venv/bin/python tools/make_logo.py
```

プロンプトとシードは `tools/gen_assets.py` の `ASSETS` にまとまっている。主人公は素体プロンプト(`BABY_CORE`)とシードを使い回すことでポーズ違いでも同じキャラに見えるようにしている。キャラの同一性をさらに上げる方法は `characters/README.md` を参照。
