# キャラクターの見た目を安定させる

同じキャラなのにポーズごとに顔や髪型が変わってしまう問題を解消するための置き場。

```
characters/
├── baby/
│   ├── refs/   ← 参考画像をここに置く
│   └── lora/   ← 学習させた場合の出力先
└── boss1/
    ├── refs/
    └── lora/
```

## 先に読んでほしいこと: LoRAの前にIP-Adapterを試したい

このマシンの状況を調べた結果、**LoRA学習より先にIP-Adapterを試すべき**です。

| | IP-Adapter | LoRA学習 |
| --- | --- | --- |
| 導入状況 | **導入済み**（`ComfyUI_IPAdapter_plus` + `ip-adapter-plus-face_sdxl` + CLIP-ViT-H） | **未導入**（kohya_ss / sd-scripts なし） |
| 学習 | 不要。参考画像を渡すだけ | 必要。数十分〜数時間 |
| VRAM | 生成時と同程度で足りる | SDXLの学習は本来10〜12GB級。**このGPUは6GB**なので、低VRAM設定でも厳しい |
| 微調整 | 効き具合を数値で即調整できる | 学習し直しになる |

つまりLoRAは「ツールを入れる → 6GBで学習が通るか試行錯誤する」という重い前段があり、そこを越えても6GBという制約が残ります。一方IP-Adapterは今すぐ試せて、キャラの同一性を保つ用途にはこれで足りることが多いです。

**まずrefs/に画像を置いてください。IP-Adapterを組み込んで結果を見て、それでも足りなければLoRAに進みましょう**（その場合はSD1.5ベースに落とすか、学習だけクラウドで回すという選択肢も含めて相談させてください）。

## refs/ に置く画像について

- **枚数**: IP-Adapterなら1〜5枚で十分。LoRAまで見据えるなら15〜30枚あると良い
- **内容**: 顔がはっきり写っているものを最低1枚。あとは全身、横向き、いろんなポーズがあるほど安定する
- **背景**: できれば単色や白抜き。背景の要素まで学習・参照されるのを防げる
- **サイズ**: 1024px前後以上。小さすぎると特徴を拾えない
- **形式**: png / jpg
- **NG**: 複数キャラが写っているもの、極端に暗い/ぼやけたもの、強い加工（フィルタ）がかかったもの

置いてもらえたら、こちらで `tools/gen_assets.py` にIP-Adapterを組み込んで全ポーズを作り直します。

## 現状の暫定対応

いまは「同じシード + 共通のプロンプト文」でキャラを揃えています（`tools/gen_assets.py` の `PLAYER_SEED` / `PLAYER_BASE` / `BOSS1_BASE`）。ポーズによってはブレが出るのはこの方式の限界です。

なお敵2（やけどのクマさん）は保留中のため、現状の方式のままにしてあります。
